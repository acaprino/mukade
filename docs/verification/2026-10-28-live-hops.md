# Live hops into Claude Code, Codex and OpenCode, with real reasoning (2026-10-28)

**Question.** Does each destination take back a session mukade wrote, resumed with a real model,
and does real reasoning (Anthropic signed thinking, Anthropic redacted thinking, OpenAI encrypted
reasoning) travel so that the destination's provider accepts it?

**Answer, in short.**

- **Claude Code** resumes mukade's sessions, signed thinking and redacted thinking included, and
  the payloads arrive byte for byte. But a copy with a tampered signature resumes too: a plain
  `claude -p --resume` does not have the provider check earlier turns' thinking, so this run does
  not prove the payloads are accepted, only that they are not refused.
- **OpenCode** resumes them as well. Through its OpenRouter provider it did not replay the
  reasoning mukade wrote at first (finding 2); after the fix it does, and the provider checks it:
  the tampered copy is refused.
- **Codex** could not be tested: the user's ChatGPT plan had hit its usage limit (until
  2026-11-04).
- **Pi** stores redacted thinking in a shape mukade read wrongly; fixed the same day (finding 1).

What the negative controls mean. Through Pi and OpenRouter the same kind of control **is**
refused (`messages.1.content.0: Invalid signature in thinking block`,
[2026-10-28-pi-reasoning-live.md](2026-10-28-pi-reasoning-live.md)): there Pi sends every earlier
turn's thinking and the provider checks it. Claude Code's plain resume and OpenCode's OpenRouter
path do not reach that check, so for them a successful resume shows the session is accepted, not
that its reasoning is.

## Findings

1. **Pi keeps Anthropic's redacted thinking as** `{type:"thinking", thinking:"[Reasoning
   redacted]", thinkingSignature:<data>, redacted:true}` and sends it back as
   `redacted_thinking {data}` (its own anthropic-messages code). mukade read that as signed thinking
   with the text "[Reasoning redacted]", and wrote it back without `redacted: true`; a hop to
   Claude Code would have written a `thinking` block instead of `redacted_thinking`. **Fixed** in
   `63bd3bd` (Pi reader and writer, `payload_fits`); the Pi → Claude row above ran on the fix.
   Anthropic's documented trigger string produced redacted thinking through OpenRouter, but not
   through Claude Code with Haiku 5.5: there the answer came without any thinking.
2. **OpenCode keeps a provider's reasoning in that provider's own `native` shape.** A reply
   through OpenRouter was stored as `native.reasoningDetails: [{type:"reasoning.text",
   format:"anthropic-claude-v1", index, signature}]`; mukade writes `native.signature` (and
   `native.encrypted`), the shape the spec records for OpenCode's own Anthropic provider. With an
   OpenRouter destination model that reasoning was therefore not replayed: the session worked, the
   reasoning was in effect dropped, and the manifest did not say so. **Fixed** the same day: toward
   the `openrouter` provider mukade writes `native.reasoningDetails` (`reasoning.text` with the
   signature, `reasoning.encrypted` with the data, `format` from the block's protocol), and reads it
   back. Rerun: the copy resumes, and the tampered copy is now refused by the provider.
3. **Claude Code with `CLAUDE_CONFIG_DIR` set**, even to its default `~/.claude`, looks for its
   configuration inside that folder and makes a new one there (`~/.claude/.claude.json`); a first
   attempt of this run did, and the file was moved out afterwards. The scripts run Claude Code with
   its environment untouched.
4. **Behind the harness's TLS-intercepting proxy** (its CA in `NODE_EXTRA_CA_CERTS`, which Node
   programs read), Codex, a Rust program, could not connect until `CODEX_CA_CERTIFICATE` named
   that CA; `live_codex.py` sets it.

## How to run it again

```sh
cargo build --release
python -I docs/verification/live-hops/live_claude.py <scratch> [<pi session with redacted thinking>]
python -I docs/verification/live-hops/live_opencode.py <scratch> <pi session, signed> [<pi session, redacted>]
python -I docs/verification/live-hops/live_codex.py <scratch>
```

`live_claude.py` must run with `CLAUDE_CONFIG_DIR` unset; `live_opencode.py` needs
`OPENROUTER_API_KEY`. The Pi sources come from `pi-reasoning-live/live_reason.py`, and the redacted
one from the same Pi command with Anthropic's trigger string
(`ANTHROPIC_MAGIC_STRING_TRIGGER_REDACTED_THINKING_46C9A13E193C177646C7398A98432ECCCE4C1253D5E2D82641AC0E52CC2876CB`)
in front of the question.
